# 手册减量：从十四条到八页

## 目标

玩家反馈「手册字太多，不会一个个看，好多跟剧情没关系」。这一轮把《新员工手册》从 14 条压到 8 页，并让「有没有用」变成能校验的事：每一页都必须写清它在剧情里的考场（`examAt`），没有考场的条款不进册子。

判据不是字数，而是**玩家读完这条，后面会不会用到**。对完 `events.json` 与《剧情册》：剧情册点名的只有 1.1 / 1.2 / 1.3 / 2.3 / 2.4 / 3.3，砍掉的 1.4 / 1.5 / 2.1 / 2.2 / 2.5 / 3.4 全年一次都没被点名。

## 输入文档

- `../剧情册.docx`：D 手册段（69–74 行）、E03 铅笔字回响（182 行）、E 手册第一章补充解锁（196–198）、第二章回响（268–270、417–420）、第三章（669–684、966–978）
- `../十二个月开发文档_V1.md` §4 数据契约（手册页字段）、§11 HUD 讲解卡
- `data/story/v12m/events.json`：四个手册节点 `M01_HANDBOOK_1` / `M02_HANDBOOK_2` / `M03_HANDBOOK` / `M07_HANDBOOK_3`，以及 E03 / M04_OPEN / M12_OPEN / E19 里逐字引用手册的台词
- `data/story/employee_handbook_12m.json`（运行时唯一读的这份）
- `scripts/HandbookPanel.gd`、`scripts/WorkplaceTown.gd`

## 关键决策

1. **砍到八页，3 / 2 / 3 分章**：1.1、1.2、1.3｜2.3、2.4｜3.1、3.2（划掉）、3.3。正文合计 747 → 约 280 字。
2. **每条只写「结论 + 代价」两行**，删掉解释性第三句。1.2 与 3.3 的铅笔字**一个字没动**——E03、M12_OPEN 是逐字引用的。
3. **1.5「你还有没有余力」移出手册**。第 2 月本来就有一张心情讲解卡把六格规则讲成三步，比手册更及时；那张卡里「《你还有没有余力》里是完整规则」改成「它不写在手册里 / 公司不记这本账」。
4. **3.2 做成被王哥划掉的一页**（`struck: true`）：标题画一道横线、正文退成铅笔色，铅笔字「转正那次不算。这条是给满一年的人写的。」。一处同时修掉「答辩每 12 个月一次」与第 6 月转正答辩的设定冲突，也让「手册是死的、人是活的」有个具体的样子。
5. **后记只印在最后一页**。以前 `afterword` 根本没渲染，而同一句话挂在 1.5 的 `margin` 上——翻到第一章中间就「手册到这里就结束了」。
6. **剧情点哪页就翻哪页**：`runner_unlock_handbook` 记下这批的第一页，`_open_month12_handbook` 调 `show_page()` 直接落过去，玩家不用自己在目录里找。
7. **校验器加两条闸门**（`tools/audit_v12m.py`）：
   - 1b 每个非 `struck` 页必须有 `examAt`，且节点真实存在；每页必须被某个手册节点解锁；
   - 1c 剧情里带「」/“”且提到手册的引用，必须在标题／正文／铅笔字里逐字找得到（E19 以前那句「临近评估再补记录」就找不到，已改成引用 3.3 的铅笔字）。

## 问题

- **两本手册并存**：`HandbookPanel` 的默认路径和 `StoryEventPanel._open_handbook()` 仍指旧 48 个月那本 `employee_handbook.json`（id 是 tech/process/promotion）。12m 流程一律显式传 `employee_handbook_12m.json`，旧的只在旧流程用到——改之前先确认改的是哪一本。
- **目录「读过/没读」标记没做**：方案里提过，这轮没落。现在只有红点和选中框；条目少，暂时够用。
- **V12CoreFlowTest / V12MilestonesTest 仍失败**，失败点是旧 48 个月口径（「3 点行动力窗口」「E07 后打开第 6 月检查点」），与手册无关，是当天其它未提交改动带下来的。没有在本轮修。
- **实机没看**：`tools/handbook_pages_probe.tscn` 只验证结构（页数、后记位置、删除线宽度 225px），配色和纸面观感要等实机。
