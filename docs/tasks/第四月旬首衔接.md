# 第四月旬首衔接

## 目标

第四个月三个旬之间要接得上：上旬→中旬、中旬→下旬各有一句交代和一屏落点，下旬不再直接跳月末卡。

- 上旬末的"两周"不能只靠旬卡一闪：旬卡要写"两周后"，中旬第一屏首拍报时。
- 中旬复盘会之后要有人收尾；下旬补一屏，把上旬王哥那句问话回答掉。
- 中旬结果页与 E05 结果重复的"两周。"删掉。

用户实况（2026-10-30 晚）：「第四个月的上中下旬没有什么衔接啊，你怎么改一下」。

## 输入文档

- 《剧情册》第四月：A 第 1 周（上旬）、B 两周之后（中旬通知）、C 第 3 周 E07、D 会后小林消息、F 月末回顾。
- 《十二个月开发文档_V1》附录 A 第 4 月设计（屏序、节点、M04_NOTICE / E07 / M04_PHONE / M04_CLOSE）、§15.12。
- `docs/design/全年旬界与节点日期同步.md`：旬卡、`gapText`、日期牌的三个同步入口。
- `AGENTS.md` 与剧情册「全年统一规则」：旬首交代、屏末交代、不预告主线、剧情必须走到才开。

## 关键决策

1. **不新造旁支，只补旬界**。新增一屏（`M04_LATE`）只回答上旬已经提出来的问题（王哥"零散的还是根本没测过"）、只回声中旬已经发生的事（纪要里写了谁）；不新增旗标、不改数值、不加手机批次。
2. **`gapText` 是旬界的正解**。旬卡只有「第几月 · 某旬 · 白天／夜里」六个字；跨区或换时段才由 `_maybe_append_departure()` 自动补收尾句，同区同时段（E05 → `M04_NOTICE`）按册子直接跳过。所以两个旬界各写一句 `gapText`（`两周后` / `几天后`），旬卡先亮"过了多久"再亮新旬。
3. **中旬首拍不再复述结果**。原三句都以"两周。"开头，与 E05 的结果隔着一张旬卡读第二遍；改成首拍报时，三句只留这一屏独有的事实（排期调整人 / 需求数 / 第二期留一半）。
4. **下旬放在夜里、工位**。王哥当晚还在（第 2 月 E03、第 5 月深夜都是这么演的），也省掉一次"白天→夜里"的额外翻牌；下一屏月末卡仍是夜里。
5. **日期字段按戏里的日子补**（上旬 1 / 中旬周一 15 / 复盘会 19 / 消息 19 / 下旬 22 / 月末 28）。日期牌只写月 / 旬 / 时段，`day` 只影响事件卡明暗与旧链路的到期判定。
6. **月末回顾从 F 挪到 G**，给下旬腾出 F，册子章节 A→G 连续，不用 `F1` 这种补丁编号。
