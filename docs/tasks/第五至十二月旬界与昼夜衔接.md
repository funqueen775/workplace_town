# 第五至十二月旬界与昼夜衔接

## 目标

第 5–12 月的旬界和昼夜要能读顺：

- 每次上旬 → 中旬 → 下旬，旬卡不能只换一个字；要说出「过了多久」（`gapText`），旬首那一屏的第一句要接得住。
- 一天之内不能上午 → 夜里凭空跳；要黑天，就得有一屏把「天黑了」说出来。
- 天黑到天亮必须有人睡过：能回家的走回宿舍（`sleepHome`），回不去的在工位趴到天亮（`allNighter`），屏末写一句「太晚了」。
- 同一天里不许连跳两旬，也不许把上一旬的事写在下一旬的牌面下。

用户原话（2026-10-30 晚）：「我发现每个月都有上中下旬没有什么衔接，很突然，然后一会黑天一会白天，要说清楚做了什么事情就到黑天了，黑天转白天一定要回去睡觉才能到白天，并说明太晚了回去睡觉吧，你从第五个月开始往后看，每个月都有这部分问题。」

## 输入文档

- `docs/tasks/第三月旬首衔接.md`（第 36 条校验规则的来历）、`docs/tasks/第2月两晚的昼夜节奏.md`（睡觉屏的写法）、`docs/tasks/第三月旬界过渡.md`（`gapText` 与黑场时长）。
- `AGENTS.md`：屏末交代三要素、剧情必须走到才开、不预告主线、改完必跑清单。

## 关键决策

1. **按月实际播放顺序（`order`）看，不看文件顺序**。`manifest.nodeOrder` 尾部还挂着后来补的节点，运行时不读它；`_load_month_nodes()` 按 `order` 排。本轮所有判断都以 `order` 为准。
2. **夜→晨只有三条合法路径**。①上一屏 `sleepHome`（走回宿舍，带 `wakePhase`）；②`allNighter`（人没走，原地趴到天亮——运行时也压黑、也亮「第二天」，只是不走位）；③这一屏写了 `gapText`（跨了好几天，不演睡觉）。三条都没有，就是「日期牌自己从夜里翻成白天」。校验器第 37 条把前两条之外的路判成错误。
3. **第 5 月那晚不能改成回家睡**。剧情册写死「今晚不回宿舍了」「趴在桌上又睡了三个小时」「上午十一点四十才坐上出租车」。所以用 `allNighter`：新增 `_do_all_nighter()`，压黑 → 黑场里亮「第二天」→ 牌面静默落到下一屏的旬 → 拉开黑场；不新增字段以外的玩法，也不改台词事实。
4. **旬界补 `gapText`，不改台词事实**。卡片先亮「第二天 / 几天后 / 一周后 / 十天后」，再换旬字；已带旬名的首句（「中旬。」「下旬。」）不动，缺旬名的补半句。
5. **第 5 月「上旬深夜 → 中旬清晨」保留**（开发册第 5 轮就这么定的：旬翻在过夜这一拍），但首句要明说「上旬过完了，今天是中旬第一天」，不能只靠「蒙蒙亮」。
6. **第 8 月 `E25` 改回上午**。`M08_BRIDGE` 末句「明天上午十点，A 区合规复盘室」，节点却写 `afternoon`；按台词改 `morning`，同旬不播卡，也不再和「明天上午」打架。
7. **第 11 月自由活动退回中旬**。`E32`（中旬·午后）之后紧跟 `M11_FREE`（下旬·午后），玩家一开自由安排牌面就跳下旬；自由安排本来就排在中旬，下旬留 `E41` 那一屏。
8. **和第 3 月那条线交接**。开工时另一条会话正在写同样的三个文件：它先把校验器第 37/38 条、第 2/3/6/12 月的 `sleepHome`、`M03_BRIDGE` / `M05_NIGHT` / `M06_WAIT` 的台词落了地。等它停手三分钟、文件 mtime 稳定后，本文件接手**复查并补齐**：第 5–12 月的 `gapText`、`E25` / `M11_FREE` 的时间回正、三处「太晚了」、`allNighter` 的运行时。没有覆盖它的任何改动。

## 问题

- **一处口径冲突，未擅自改**：`M11_OPEN` 说「上旬末前把你的材料给我」，可材料那两屏（`M11_MATERIAL` / `E32`）排在上旬末到中旬，提名（`M11_NOMINATION`）在下旬。要么把「上旬末」改成「这周内」，要么把材料往前挪一天；两条都动剧情册原话，留给下一轮定。
- **`M11_PHONE_CG` 说「十二月上旬，上午九点」，`M12_DOOR` 说「十点前先把材料放好」**，九点/十点不一致；本轮只记，不改。
- **第 1–3 月各有一处同类问题**（`M01_HANDBOOK_1 → E02` 跨旬无 `gapText`、`E03 → M02_HANDBOOK_2` 上旬直接跳下旬、`M03_BRIDGE` 首拍没写天黑——最后这条另一条线已补「收工的时候，天已经黑了」）。本轮按用户指定的范围从第 5 月起；1–4 月等下一轮一起收。
- **`_do_all_nighter()` 只过了静态编译**：本机 `user://` 不可写、探针起不来，压黑→天亮这一段还没实机看片（见待同步项）。
- 本机 shell 对 `workplace_town/` 的写入仍受 Windows 权限限制（数据是编辑工具改的）；Godot 两个场景测试有既有失败（`V12CoreFlowTest` 的 NPC 交流入口、`V12MilestonesTest` 的第 6 月检查点），与本轮无关。
