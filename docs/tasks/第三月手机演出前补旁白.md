## 目标

第 3 月 E10「保证不胡说」客户展厅那一段，王哥的消息气泡从右下角弹出来之前，先有一句旁白说明手机震了，别让手机凭空出现。

- 文案以剧情册 C 段 E10 为准，不另写。

## 输入文档

- 剧情册 C「E10 保证不胡说」：`【旁白】 手机震了一下，屏幕上出现王哥的消息气泡；不进收件箱，没有红点。`（在客户「出了问题谁负责」之后、王哥消息之前）。
- 开发册 §4 第三月节点表与 E10 拍序列。

## 关键决策

1. **只加一条 `narration` beat**，位置在 `方经理：别跟我讲概率…` 之后、`phone_cinematic` 之前，恰好对应剧情册第 243 行那一拍。其它拍序、选项、旗标、数值一概不动。
2. **文案逐字用剧情册**：`手机震了一下，屏幕上出现王哥的消息气泡。` 剧情册句末的「不进收件箱，没有红点」是实现说明，不是玩家台词——`PhoneInboxPanel.peek_message()` 本来就不置已读、不进会话列表、不出回复项，这句已由代码保证，写进旁白反而像在讲 UI。
3. **不改 `phone_cinematic` 的行为**：剧情里的手机仍是右下角抽屉拉开、停住等玩家自己收起，收起后才继续下一拍（`_peek_phone_for_story` / `_after_story_phone_closed`）。补旁白只解决"先响一声"的因果，不动交互。
