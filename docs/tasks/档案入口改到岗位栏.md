# 档案入口改到左上角岗位栏

## 目标

玩家要求：右下角那颗「档案」圆钮不要了，改成点左上角那条岗位栏（`当前职位 实习开发师`）开档案。2026-10-30 当天定。

## 输入文档

- 玩家两张截图：右下角「档案」圆钮 + 左上角岗位栏
- `scripts/TownUiV2.gd`：`_job_label`（岗位栏）、`_hud_round_button()` / `_layout_bottom_buttons()`、`archive_requested` 信号、`set_archive_visible()`
- `scripts/WorkplaceTown.gd`：信号连线（1750）、`set_archive_visible()` 两处调用（月首 3928 / 月末 5164）、第一次翻档案的讲解卡（`_open_ui_profile`）
- `tools/hud_check.gd`：早就写好了 `archive_button_gone` 与"点岗位栏"两条检查——说明这个改法本来就是既定方向，只是代码里没落完

## 关键决策

1. **圆钮整个删掉，不是隐藏**：`const HUD_ARCHIVE`、`var _archive_button`、建钮与 caption 三行、`_layout_bottom_buttons()` 里的槽位、`set_archive_visible()` 全删。底排只剩手册 / 手机 / 设置，仍然只给可见的排槽、贴右侧，不留空位。
2. **岗位栏从"只读岗位牌"改成按钮**：`mouse_filter` 由 `IGNORE` 改 `STOP`，手型光标，`pressed` 接新信号 `profile_requested`。信号由 `archive_requested` 改名而来——入口已经不是那颗圆钮，名字再叫 archive 会误导后来的人。
3. **两个入口都留着**：第一次点岗位栏仍走 `_show_hud_button_tutorial("profile")` 的讲解卡（看过后不再弹）；月末回顾卡上的「打开档案」走 `Month12ClosePanel` 自己的 `archive_requested`，与本次无关，不动。
4. **处境那行字**挂在岗位栏下方，点它同样开档案（原来就发这个信号，跟着改名）。
5. 牌面是张图，没有按钮样式的 hover，补了一点提亮（`modulate` 1.06）当可点提示，鼠标移开复原。

## 讲解时机（第三轮，2026-10-30 玩家定）

原来讲解卡只挂"第一次点职位卡"，而职位卡从开局第一天就能点 —— 讲解可能提前到首月开局，月末回顾卡那个入口又不弹卡，于是"什么时候讲"完全取决于玩家点不点。玩家拍板：**档案锁到月末，回顾卡关掉后自动讲一次，讲完再回宿舍**。

实现：

| 东西 | 干什么 |
|---|---|
| `_archive_open_allowed` | 月末回顾卡关掉时才置真；之前点职位卡 / 处境字只出提示条「月末再翻 · 这个月的记录要等月底才收进档案」，不弹空档案 |
| `_unlock_archive_then(after)` | 解锁 + 自动弹一次讲解卡；卡关掉（「打开档案」或「稍后」都算）才 `after.call()` |
| `_archive_card_offered` | 自动讲解一局只弹一次：被「稍后」挡掉后，改成玩家自己点职位卡时再出（与 §4.24 "稍后不算看过"一致） |
| `_after_profile_step` / `_pending_after_profile` | 点「打开档案」时，等档案页**关掉**再继续走回宿舍，别把页面顶在过场下面 |
| `_continue_after_month_close()` | 把 `_on_month12_close_finished` 后半段（第 6 月判定 / 第 7 月提前收口 / 第 12 月翻月 / 走回宿舍）原样挪进来，插在讲解之后 |

一个坑记下来：`HudButtonTutorialCard._on_open_pressed()` 是**先 `_close()`（发 `closed`）再开页**，所以在 `closed` 里同帧判断"页面开没开"一定是 false。`_on_profile_card_closed()` 用 `call_deferred` 等一帧再判断。

验证（临时探针，跑完已删）：

- 开局点职位卡：`页面=false 讲解卡=false`（只出提示条）
- 回顾卡 `finished` 之后：`讲解卡=true unlock=true`
- 点「打开档案」→ `页面=true view=profile`；关掉档案页 → `phase=sleep_walk`
- 点「稍后」→ `phase=sleep_walk 页面=false`；之后再点职位卡 → `讲解卡=true`（还能补看）

## 讲解时机（第四轮，"第一次"落在哪儿）

上一轮把讲解放在"回顾卡关掉之后"，玩家指出：**第一次真正翻开档案其实是在回顾卡里点「打开档案」那一刻**，那时没有解释，讲解晚了一步。改成：

| 路径 | 现在的行为 |
|---|---|
| 回顾卡里点「打开档案」 | 先把回顾卡藏起 → **弹讲解卡** → 点「打开档案」开页 → 关页 → 回顾卡原样放回 → 关回顾卡走人 |
| 点「稍后」 | 回顾卡原样放回（不留在空屏），提示语换成「回顾还在这儿 · 想看档案，随时点左上角那一格」；之后自己点职位卡可补看 |
| 没点那行、直接关回顾卡 | 关掉后补弹一次讲解，讲完再走回宿舍 |
| 之后任意月份 | 职位卡随时翻，不再弹卡；同一局只自动弹一次 |

实现补充：

- `_open_archive_from_close_card()` 改成先走讲解卡；`_show_hud_button_tutorial()` 加了可选参数 `later_toast`，「稍后」那句提示按入口换。
- `_after_close_card_profile_card()` / `_resume_after_close_card_profile_card()`：卡关掉后延一帧判断页面开没开——开着就等关页（`_on_ui_view_closed` 放回回顾卡），没开就把回顾卡放回来。
- `_archive_card_offered` 在回顾卡这条入口也要置真，否则关掉回顾卡时会在 `_unlock_archive_then()` 里再弹一次。

验证（临时探针，跑完已删）：

- 「打开档案」：`讲解卡=true 回顾卡隐藏` → `页面=true` → 关页 `回顾卡可见=true` → 关回顾卡 `phase=sleep_walk 讲解卡=false offered=true`
- 「稍后」：`页面=false 回顾卡可见=true` → 关回顾卡 `phase=sleep_walk`
- 直接关回顾卡：`讲解卡=true`（补讲一次）
