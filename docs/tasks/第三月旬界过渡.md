# 第三月旬界过渡（过了多久 / 天黑分两段）

## 目标

把第 3 月三次旬界从「旬卡一闪就换地方」改成「先说清过了多久，再换旬」，并把走位途中换昼夜从「0.6 秒一枪压黑」改成「黄昏 → 入夜」两段。具体三件：

1. 跨旬卡先亮一句时间跨度（`gapText`：`两周后` / `一周后`），再让新旬字进来；这一拍不甩色条、不砸字。
2. 走位途中换昼夜时，世界光照跟着整段路慢慢暗（3.2 秒两段：暖橙→夜蓝）；原地换旬 1.8 秒；宿舍熄灯 0.3 秒。
3. 第 3 月内容收口：`M03_MID` 删掉与 `M03_NOTICE` 逐字重复的三条「合同签了……」；`M03_LATE` 首拍「这一旬」改成「下旬」。

二轮（用户补充）：天变黑要说清这段时间干了什么；天黑到天白必须回宿舍睡觉。两条都要变成全年规矩，不是只补第 3 月。

## 输入文档

- 剧情册：F1 中旬（两周后报时）、F2 下旬、E12。
- 算法册：本月零选项、零数值变化，不需要改。
- 开发册 §4 节点字段表（新增 `gapText`）、§4.14 过场档位（旬卡 / 昼夜光带时长与做法）。
- `docs/design/全年旬界与节点日期同步.md`：日期对齐的接口口径。
- `AGENTS.md`：过场只说「何时何地」不预告主线；文案进 JSON；结构性改动先给方案。

## 关键决策

1. **时间跨度做成数据字段，不做成新节点。** 加 `gapText`（可选）而不是给第 3 月插一个「两周过去了」的过场屏：不新增节点、不加选项、不动 `nodeOrder`，全年 19 处跨旬可以逐月补，不补的保持原样。
2. **带 `gapText` 的旬卡改静。** 原来的「旧字甩出 → 新字砸入 + 抖动」是为同一旬内的快切设计的；跨两周这种跨度再用砸的，读起来像被打断。所以这一档改成：慢压暗 → 时间跨度淡入 → 停 0.5 秒 → 淡出 → 新旬字淡进，不甩色条。实测 1.42 秒 → 2.67 秒。
3. **天黑不改触发时机，只改时长与配色。** 日期牌仍然在出发前翻（三轮的结论，避免"走到一半时间变了"），改的是光照本身：两段 + 三档时长。走位档由 `_walk_date_first()` 预留 `_band_fade_seconds`，`_apply_date_band()` 用完即清，避免漏给下一次不相干的昼夜切换。
4. **重复的三句只删不加。** `M03_NOTICE` 与 `M03_MID` 讲的是同一批合同结果；报时那屏讲结果、周会那屏讲当场，删掉后一屏的重复，不新造台词。
5. **信号连接走窄壳。** `band_lights` 只带一个参数，`_apply_date_band()` 现在有两个参数（第二个有默认值），不依赖"默认参数能不能接信号"，改由 `_on_band_lights()` 转手。

### 二轮：天黑与睡觉（2026-10-30 晚）

6. **入夜必须交代「这段时间在干什么」。** 天不是自己黑的；进夜那一屏的台词里要读到「忙到收工 / 改到傍晚 / 天已经暗了」。不新造事件，只把"这段时间"补进已有首拍：`M03_BRIDGE` 首拍改「忙到收工，天已经黑了。回到工位。…」，并补 `walkNote` 让玩家在走位途中就知道自己在干嘛；`M06_WAIT` 首拍改「等到天黑，回到工位。」。校验器第 38 条（WARN）盯这条，关键字表在 `tools/v12m_validate.py`。
7. **夜里→白天一律走 `sleepHome`，不站在原地看天亮。** 同月相邻两屏「night→morning」时，前一屏写 `sleepHome`：走回宿舍、进门熄灯、黑场、天亮再回来。这是现有机制（第 2 月两晚已经在用），本轮把它变成全年硬规矩并补上缺的屏：第 3 月 `M03_BRIDGE`、第 6 月 `M06_WALL_OUT`（`wakePhase: "mid"`）、第 12 月 `M12_OPEN`（`wakePhase: "mid"`）。
8. **通宵留一个显式例外。** 第 5 月 `M05_NIGHT` 是人没走、改到凌晨，写 `allNighter: true` 替 `sleepHome` 放行；天亮由 `M05_DAWN` 首拍「你处理完的时候，天已经蒙蒙亮了」交代。例外必须写字段，不许靠"这屏没写 sleepHome"默认放过。
9. **第 3 月的时序因此变成**：上旬收工（天已黑）→ 回宿舍睡（黑场里亮「两周后」，醒来牌面直接是中旬白天）→ 走回工位 → 中旬报时屏 → 中旬周会散场 → 「这几天一有空就补那个数的来源，再抬头窗外已经黑了」→ 旬卡「一周后·下旬」→ 下旬屏。
