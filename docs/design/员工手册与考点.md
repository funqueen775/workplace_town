# 员工手册与考点（12m_v1）

《新员工手册》是 E01 的核心可交互物，也是十二个月里唯一一件**能被反复翻开、且内容会随月份变多**的物件。这份文档只写它怎么落地：收哪些页、页上有什么字段、面板怎么开、校验器拦什么。玩家看到的原话以《剧情册》与 `employee_handbook_12m.json` 为准。

## 1. 定位

手册不是入职读物，是**这一年会被考的规矩 + 有人用过的痕迹**。

1. **只收有考场的条款。** 每一页都要能指出它在剧情里的落点（`examAt`）；找不到落点的通用职场常识不进这本册子。玩家扫一眼就该知道"这条以后会用到"。
2. **一页两行。** 一条只写结论和代价，不写解释性第三句；引用原话（铅笔字）一字不改，因为剧情会逐字引用它。
3. **痕迹优先于规则。** 铅笔字是王哥的（`marginOwner`），被划掉的条款（`struck`）比新增条款更有信息量：它说明这本册子有人不同意。

## 2. 数据结构

文件：`data/story/employee_handbook_12m.json`（运行时唯一读的那份；`data/story/employee_handbook.json` 是旧 48 个月那本，只读）。

```json
{
  "title": "新员工手册",
  "edition": "第一版 · 内部资料",
  "issuer": "小熊镇 · 研发中心",
  "marginOwner": "王哥",
  "marginHint": "册子边上有铅笔写的字",
  "chapters": [
    {
      "id": "1.1",
      "index": 1,
      "title": "提交之前，先答三个问题",
      "subtitle": "第一章 · 技术规范",
      "lead": "先把这三个问题答完，再谈写得快不快。",
      "clauses": [
        {
          "id": "1.1",
          "title": "提交之前，先答三个问题",
          "body": "改了什么、为什么必须这么改、出问题怎么验证。答不全，就先别提交。",
          "pencil": "王哥写在页边的铅笔字，可省",
          "struck": false,
          "examAt": ["E01", "E02"]
        }
      ],
      "margin": "读到章末才浮出来的批注，可省"
    }
  ],
  "afterword": "手册到这里就结束了。剩下的，得由坐在你旁边的人告诉你。"
}
```

| 字段 | 类型 | 约束 |
|---|---|---|
| `chapters[].id` | string | 稳定 ID，形如 `章.条`（`1.1`、`2.3`），目录按点号前一段分章 |
| `chapters[].subtitle` | string | `第N章 · 章名`，目录组标题取点号前一段 |
| `clauses[].body` | string | ≤ 45 字；结论在前，代价在后 |
| `clauses[].pencil` | string | 玩家可见的人话；**不许出现事件编号**；被剧情逐字引用时不能改 |
| `clauses[].struck` | bool | 被划掉的那一页：标题画横线、正文退成铅笔色；`examAt` 可为空 |
| `clauses[].examAt` | string[] | 剧情里用它的节点 id；非 `struck` 页必填，节点必须存在 |
| `afterword` | string | 只印在**最后一页**末尾 |

解锁节奏在 `data/story/v12m/events.json` 的 `nodeType: "handbook"` 节点里，`pages[]` 只放 `pageId / title / bodyKey`：

| 月份 | 节点 | 页 |
|---|---|---|
| 1 | `M01_HANDBOOK_1` | 1.1、1.2 |
| 2 | `M02_HANDBOOK_2` | 1.3 |
| 3 | `M03_HANDBOOK`（silent，只亮红点） | 2.3、2.4 |
| 7 | `M07_HANDBOOK_3` | 3.1、3.2、3.3 |

解锁时写旗标 `handbook_page_<pageId>`，剧情用它分支（E03「读过 1.2 才想起那句铅笔字」、M04_OPEN「读过 1.3」、E19「读过 3.3」）。

## 3. 接口

`scripts/HandbookPanel.gd`（`class_name HandbookPanel`，`CanvasLayer`，layer 160）：

```gdscript
signal handbook_closed(records: Dictionary)  # {totalMs, chapters: {id: {visited, dwellMs, skipped}}}
func open(data: Dictionary = {}) -> void    # 不传就用旧 48 个月那本；12m 一律显式传
func show_page(page_id: String) -> void     # 剧情点名的那一页，翻过去；找不到就停在原页
func chapter_ids() -> Array                 # 目录顺序
func is_open() -> bool
func close() -> void
```

`scripts/WorkplaceTown.gd`：

- `_open_month12_handbook()`：读 `MONTH12_HANDBOOK_PATH` → `open()` → 有 `_handbook_pending_page` 就 `show_page()`；顺手灭红点。
- `runner_unlock_handbook(node)`：写 `handbook_page_*` 旗标、亮红点，并把 `pages[0].pageId` 记进 `_handbook_pending_page`。
- `_on_month12_handbook_closed()`：置 `_month12_flags.handbook_read`；首月讲解卡选了「打开手册」的，合上后接 E02。

## 4. 版面

- 页 1348×848，目录 330，正文 `CONTENT_W = 1348 - 330 - 64×2 - 14`；字号统一乘 `TYPE_SCALE = 1.18`。
- 目录按章手风琴，一次只摊一章；八条之后一屏放得下，但仍保留折叠（旧数据有 14 条时的遗留）。
- `struck` 页：标题 `vertical_alignment = CENTER`，子 `ColorRect`（名 `Strike`）按字体量出的文字宽度画 2px 横线，`resized` 时重摆——Label 不是容器，只能这么挂。
- `afterword` 只在 `_is_last_chapter()` 为真时追加，前面加一条分隔线。

## 5. 校验

`tools/audit_v12m.py`：

- **1** 手册节点解锁的 `pageId` 必须在 `chapters` 里存在，否则玩家点开「有新页」是空的。
- **1b** 每个非 `struck` 页必须有 `examAt` 且节点存在；每个 `chapter` 必须被某个手册节点解锁。这条是"别再往手册里塞通用常识"的闸门。
- **1c** 剧情里提到手册、且带「」/“”引号的句子，引号内文字必须在标题／正文／铅笔字里逐字存在。

`tools/handbook_pages_probe.tscn`：无渲染体检——八页、每页有字、3.2 有删除线、后记只在最后一页。

## 6. 与三册的关系

- 手册正文的口径以《剧情册》D 手册段为准；《剧情册》说"条文沿用手册源文"，所以正文只在这份 JSON 里长，不在册子里重复。
- 改动顺序：`employee_handbook_12m.json` → `events.json` 的 `pages` / `examAt` → `audit_v12m.py` 跑绿 → 回写《剧情册》引用它的那几段。
- 与《算法册》无关：手册不给分，只给"这条以后会被考"的预期。
