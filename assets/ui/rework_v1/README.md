# UI 改造资源索引

这批资源对应《熊心壮职 前端界面改造方案 V1.0(2)》。资源按功能归档，运行时只使用可替换文字的独立分件。

## 主世界 HUD

- `hud/components/`：最终补充的独立分件，共 13 张。
- 推荐组合：`章节栏_无字底板`、`职位栏_空白底板`、`职位栏_小头像框`、`精力条_空白底板`、`蜂蜜罐_满`、`蜂蜜罐_空`、`任务名称_空白小底板`、`任务_定位图标`、`查看按钮_无字`、`手机按钮_无红点`、`通知_红点`、`日历_固定图标按钮`、`推进月份_无字标签`。

## 主线任务册

- `task_book/`：主线任务页面的完整分件，包括书本底图、任务标题、锁定状态、会议插画、信息栏、条件区、追踪和推进按钮等。
- 这些图片保留透明背景和原始中文命名，接入代码时通过统一常量引用，不再放回项目根目录。

## 员工档案

- `profile/components/01_基础面板/`：空白大底板、关闭按钮、标题牌、头像框和玩家头像。
- `profile/components/02_进度与能力/`：晋升进度、能力区底板、能力图标和五色刻度。
- `profile/components/03_人际关系/`：关系底板、关系条目、爱心、爪印和四位 NPC 头像。
- `profile/components/04_职业履历/`：履历底板、入职/完成/考核节点和公文包图标。

## 接入约定

- UI 脚本统一从 `res://assets/ui/rework_v1/` 引用资源。
- `reference_full_v1` 只用于对照整体构图，不作为运行时组件，避免整张图遮住文字和交互。
- 美术替换时保持资源语义和透明边界不变，逻辑脚本无需改动。
